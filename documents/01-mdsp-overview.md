# Markdown Screenplay Overview

Markdown Screenplay, or `.mdsp`, is a lightweight screenplay format designed for easy authoring and consistent rendering.

## Goals

- Keep the authoring format readable in plain text
- Support screenplay structure without requiring a heavy editor
- Make the format reusable across viewers, editors, and tooling
- Allow metadata and advanced features without disrupting the simple writing flow
