# Markdown Screenplay Syntax Basics

## Scene transitions

Use `:` to mark scene transitions.

Example:
: CUT TO:

This also defines the difference between a main scene and a sub scene.

## Scene headings

Use `@` to mark scene headings.

Example:
@ INT. KITCHEN – NIGHT

## Dialogue

Use `>` to start a character name line and `>>` for dialogue lines.

Example:

> MORGAN
>
> > We need to leave now.

## Parentheticals

Use `>> ( )` to mark parentheticals.

Example:

> > (quietly)
